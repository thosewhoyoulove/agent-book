# World BGM drop zone

把三首主题曲放到这个目录，文件名按下面约定即可自动接入：

| 世界 | 推荐文件名（任选其一后缀） |
|------|---------------------------|
| 星露谷物语 | `stardew.ogg` / `stardew.mp3` / `stardew.wav` |
| 蔚蓝 | `celeste.ogg` / `celeste.mp3` / `celeste.wav` |
| 空洞骑士 | `hollow.ogg` / `hollow.mp3` / `hollow.wav` |

## 建议规格
- 格式优先：`.ogg`（体积小）或 `.mp3`
- 时长：30 秒～3 分钟循环段即可（引擎会 loop）
- 响度：尽量三首峰值接近，避免切换时忽大忽小
- 也可提供带淡入淡出的 loop 友好版本
